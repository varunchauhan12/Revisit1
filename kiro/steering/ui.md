# UI Guidelines

## Design direction

The application should feel:
- modern
- minimal
- premium
- responsive
- visually polished

## Design system

Use the colors defined in the existing design/reference files.

Do not randomly introduce new colors.

## Components

Prefer reusable components over duplicated markup.

Examples:
- Button
- Input
- Card
- Modal
- BottomNavigation
- Header
- Avatar
- EmptyState

## Spacing

Use a consistent spacing system rather than arbitrary pixel values.

## Typography

Use the application's configured font.
Do not introduce additional fonts unless explicitly required.

## Responsiveness

The UI must work across:
- mobile
- tablet
- desktop

Do not simply scale the mobile UI to desktop.

## Visual accuracy

When implementing a screen from a reference image:
1. Match overall layout first.
2. Match spacing.
3. Match typography.
4. Match colors.
5. Match borders/radius/shadows.
6. Match responsive behavior.
7. Only then add animations.

Do not replace the design with generic UI patterns.
